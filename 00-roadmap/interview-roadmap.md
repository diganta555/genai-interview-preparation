# Interview preparation roadmap

1. Fundamentals: explain ML metrics, embeddings, attention, and next-token generation.
2. Coding: solve chunking, cosine, async batching, retrieval, and tool validation with tests.
3. RAG: diagnose a failure using stage-level evidence and a fixed benchmark.
4. Agents: explain permissions, state, budgets, replay, and recovery.
5. Evaluation: separate hard invariants from semantic judgments and report uncertainty.
6. System design: clarify requirements, estimate workload, draw boundaries, and reason through failures.
7. Project discussion: show one implemented project, real results, trade-offs, and limitations.
8. Senior follow-ups: cover migrations, tenancy, incidents, budgets, audit, and rollback.

Use the question banks for preparation and the mock CLI for retrieval practice. Do not memorize paragraphs verbatim. Answer in your own words and provide one concrete example from work you actually performed.
